Integrasi SAP

Hubungkan web ini ke API SAP, pantau sinkronisasinya, dan kelola picklist yang diterima. Hanya superadmin yang bisa membuka halaman ini.

Web ini menarik data dari SAP lewat API-nya. Server tempat web berjalan harus bisa menjangkau alamat SAP, jadi coba dulu dari jaringan kantor. Password/token SAP disimpan terenkripsi dan tidak pernah ditampilkan lagi.

Koneksi ke SAP

Isi alamat API, cara login, dan nama field SAP. Tombol "Simpan & tes koneksi" menyimpan lalu mencoba mengambil data tanpa menyimpannya ke daftar picklist.

Riwayat sinkronisasi

30 percobaan terakhir (manual, otomatis, dan tes).

Picklist yang diterima

100 terbaru. Klik "Lihat baris" untuk melihat isinya.

Sinkron otomatis di server (cron)

Agar centang "Sinkronisasi otomatis aktif" bekerja, tambahkan satu cron job di cPanel (Cron Jobs, tiap menit). Ganti USERNAME dan FOLDER sesuai server:

* * * * * /usr/local/bin/php /home/USERNAME/FOLDER/artisan schedule:run >> /dev/null 2>&1
